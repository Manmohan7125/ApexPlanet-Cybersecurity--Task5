## 2. Methodology
1. Confirm authorization and scope.
2. Verify connectivity only to the lab target.
3. Identify the application and its security configuration.
4. Run controlled checks against the deliberately vulnerable DVWA lab.
5. Record each test, actual result, and screenshot.
6. Map confirmed findings to an appropriate category (for example, OWASP Top 10) where applicable.
7. Recommend mitigations and retest after changes if possible.
