# Project Plan and Scope

## 1. Project title
Web Application Security Assessment and Incident Response using DVWA

## 2. Objectives
- Assess a deliberately vulnerable web application in a controlled lab.
- Identify and document confirmed security weaknesses.
- Recommend practical mitigations and, where possible, validate fixes.
- Practice an incident-response workflow using a simulated lab event.
